    21→1. TECH STACK & LIBRARIES (critical — must replicate to match feel)
    22→═══════════════════════════════════════════════════════════════
    23→- Static HTML pages, no framework (Next.js / React not used by original)
    24→- jQuery (loaded inside app.js bundle)
    25→- GSAP 3 with plugins: SplitText, DrawSVGPlugin, ScrollTrigger (registered at top of custom.js)
    26→- LocomotiveScroll — hijacks the `.content` element's scroll on desktop (>1024px) for smooth inertia scrolling. On mobile (<1025px) it does NOT transform content; native scroll is used and ScrollTrigger uses `pinType: "fixed"`
    27→- smoothState.js — prefetches and AJAX-loads internal pages with a Lottie SVG page-transition animation (`js/data.json`), 1550ms duration. CSS classes `is-exiting`, `is-animating` drive the transition. Background colour is reset to #ffffff after each page load.
    28→- Lottie (airbnb) for the page-to-page transition animation
    29→- imagesLoaded — preloads all images before removing the `.loading` class (full-screen white overlay) and running the intro timeline
    30→- Siema (slider lib) referenced but actually a custom Slider class is used for drag interactions (see custom.js lines 770-960)
    31→- Prismic.io image CDN (`images.prismic.io/hobokenyogi/...`) — every image is served with `?auto=format,compress&q=90&w=XXX` and explicit 1x/2x srcsets
    32→- No build step — plain CSS file (`css/styles.css`) and two JS files (`js/app.js` bundle + `js/custom.js`)
    33→- Built by "Buzzworthy Studio" (credited in footer)

   330→▌ PAGE LOAD / INTRO TIMELINE (only on .home page)
   331→After imagesLoaded completes, body loses `.loading` class (which was overlaying a white ::before). Then a GSAP timeline `introTimeline` plays:

   334→3. `.home-img` (hero portrait) animates FROM: opacity:0, y:250, x:"-50%", rotation:25, 1.5s Quint.easeOut (starts off-center and rotated, slides in)
   335→4. `.spin div` (the "Local & Global Retreats" label) fades in FROM opacity:0 y:30, 1.5s Quint.easeOut
   336→5. `.spin img` (the 2 wave-circles) stagger FROM scale:0.2, opacity:0, rotation:135 or 150, 1.5s Quint.easeOut, stagger 0.2
   337→6. `#nav` fades in FROM opacity:0 y:-80, 1.25s Quint.easeOut
   338→7. `.progress-circle` fades in FROM opacity:0, 1.5s Quint.easeOut

   340→
   341→On non-home pages: a simpler `randomLetTimeline` plays — `.lettering` chars stagger FROM y:20 x:50 rotation:30 rotationX:90 opacity:0 (0.7s power4.Out, stagger 0.065), then `randomLetterScroll` loop starts.
   342→
   343→▌ RANDOM LETTER SCROLL (continuous, on every page)
   344→A `requestAnimationFrame` loop runs continuously. For each `.lettering div` that's currently in the viewport (±200px buffer), it sets `gsap.to(letter, { duration:1, y: Math.abs(distance * randomVal / 3) })` where `distance` is the content's bounding rect top (negative when scrolled down) and `randomVal` is a per-letter random 0-1 value generated on page load. This means each letter drifts downward at a different random rate as you scroll, creating a "loose/jiggly" typographic effect. Letters return to position when scrolled back.
   345→
   346→▌ SMOOTH SCROLL (LocomotiveScroll, desktop >1024px only)
   347→- `new LocomotiveScroll({ el: document.querySelector(".content"), smooth: true })`
   348→- ScrollTrigger is wired to use LocomotiveScroll as the scroller proxy
   349→- Native scrollbar is hidden (`.c-scrollbar { display:none }` actually removes any scrollbar that Locomotive adds)
   350→- `overscroll-behavior: none` prevents bounce
   351→- User-select disabled to prevent text selection during drag interactions
   352→- `window.onbeforeunload` forces scroll to top on page reload
   353→
   354→▌ PARALLAX (desktop >1024px, requestAnimationFrame loop)
   355→- Elements with `.parallax` (often wrapping `.img-container`) read `data-parallax="0.X"` attribute for speed
   356→- The `looper()` function runs continuously. For each parallax section in viewport: calculates distance from viewport center, applies `TweenMax.to(parallax, 1, { y: dist * speed, ease: Quart.easeOut })`
   357→- Speeds seen: 0.0 (no movement, used as a "register" element), 0.05, 0.08, 0.1, 0.15, 0.2, 0.25, -0.08, -0.1 (negative moves opposite direction)
   358→- Multiple parallax elements on a page move at different speeds for depth
   359→
   360→▌ SCROLL-TRIGGERED REVEALS (.view → .in-view pattern)
   361→- Elements marked `.view` start in their hidden/pre-animation state (defined per-component in CSS)
   362→- An IntersectionObserver with threshold:0 watches all `.view` elements. When intersecting, adds `.in-view` class — never removes it (one-shot animations)
   363→- CSS transitions then animate from hidden to revealed state
   364→- Common patterns:
   365→  - `.button.view` starts opacity:0 translateY(100px) rotate(7deg) → in-view opacity:1 translateY(0)

   369→  - `.retreat-item.view` starts translate(50%,50%) scale(1.3) rotate(-20deg) → in-view identity
   370→  - `.img-container.view` (homepage retreats) starts translate(-150% or 150%, 0%) rotateY(±90deg) → in-view identity (3D flip-in from sides)
